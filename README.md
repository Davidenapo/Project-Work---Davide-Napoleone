Project Work: Sostenibilità d'Impresa - Consorzio Melinda 
(Corso di Laurea Triennale in Informatica per le Aziende Digitali - L-31)
Ciao! Questo repository contiene il codice sorgente del mio elaborato finale (Project Work - Traccia 17). L'obiettivo del progetto era sviluppare una pagina web dedicata alla divulgazione delle pratiche ESG e al download dei report di sostenibilità di un'impresa operante nel settore primario.
Il Progetto
Ho scelto di focalizzare il mio lavoro sul Consorzio Melinda. Trattandosi di un'eccellenza del settore agricolo italiano, rappresenta un caso studio perfetto: un'azienda fortemente radicata nel territorio che ha integrato la sostenibilità (ambientale, sociale e di governance) nel proprio modello di business, rendicontando i risultati secondo i rigorosi standard europei GRI.
Invece di limitarmi a una semplice lista di file da scaricare, ho progettato una landing page moderna, accessibile e interattiva, pensata per comunicare i valori del consorzio prima ancora di proporre i documenti tecnici.
Funzionalità principali
•	Hero interattiva: Un'introduzione visivamente d'impatto con animazioni procedurali (particelle fluttuanti) per catturare l'attenzione dell'utente.
•	Sezione KPI: Contatori numerici animati allo scroll per evidenziare subito i numeri chiave del consorzio (famiglie socie, dipendenti, ecc.).
•	Manifesto ESG: Tre card tematiche (Ambiente, Società, Etica) che riassumono le azioni concrete dell'azienda.
•	Archivio Documentale Doppio: I report di sostenibilità sono scaricabili tramite card grafiche (per gli utenti comuni) e tramite una tabella dati accessibile (ideale per analisti o stakeholder istituzionali).
Stack Tecnologico
Ho scelto un approccio completamente nativo ("Vanilla"). Niente framework pesanti o librerie esterne: volevo mantenere il controllo totale sulle performance, sul design e sull'accessibilità del codice.
•	HTML5: Struttura rigorosamente semantica. Ho prestato particolare attenzione all'accessibilità inserendo skip-link per la navigazione da tastiera, tag aria-label e attributi per gli screen reader.
•	CSS3: Design interamente customizzato. Ho utilizzato le variabili CSS (Design Tokens) per una gestione coerente della palette colori aziendale, layout moderni basati su CSS Grid e Flexbox, e media queries per garantire una perfetta fluidità su smartphone e tablet.
•	JavaScript (ES6): Script leggeri e mirati per la gestione del menu hamburger mobile, l'effetto di comparsa degli elementi allo scroll (Intersection Observer), l'animazione dei contatori e la generazione procedurale degli effetti di background.
